# Personal Blog Website

A personal blog website built using React and Vite.

## Features

- Blog header
- About section with blog logo
- Dynamic article list
- Reusable Article component
- Props-based data sharing

## Technologies

- React
- JavaScript
- JSX
- CSS
- Vite

## Installation

1. Clone the repository.
2. Install dependencies:

   npm install

3. Start the development server:

   npm run dev

4. Open the local URL provided by Vite.

## Testing

Run:

npm test
